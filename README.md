# 绍派伤寒 · 学术知识图谱

> **沈钦荣名中医 × 医哲未来人工智能研究院 联合研发**
> Jointly developed by Dr. Shen Qinrong & IMPFAI

绍派伤寒（Shaoxing Cold-Damage School）学术知识图谱的网页版。发端于明代张景岳，
形成于清代俞根初《通俗伤寒论》，光大于何廉臣——以图谱之形重现越中外感病学派的
医家、著作、学说、四诊征象、方药配伍与病证治法。

**当前版本 V4**：4,317 节点 / 3,144 关系，**四层全备**——谱系层、诊法层、本草方剂层、证候层。

## 功能

**主页**

- 江南水乡首屏场景（会稽远山、白墙黛瓦、石拱桥、鉴湖水波、乌篷船），支持鼠标视差
- 学派源流时间轴：明代张景岳 → 清代俞根初 → 何秀山 / 章虚谷 / 赵晴初 →
  何廉臣 → 曹炳章 / 胡宝书 → 徐荣斋 → 当代整理与智能化
- 学术特色六端，每条均附原书文句与出处医家
- 代表医家十二家卡片，点击直达图谱对应节点
- 诊法层：征象模态分布、证候的六经与性质坐标
- 方药层：方剂配伍卡（含君臣佐使与原剂量）、剂量分布、连通性改善说明
- 证候层：《通俗伤寒论》病证分类树、六经统六法、症状类留空的理由
- 图谱实时预览（取真实布局坐标绘制）
- 机器可读数据集下载

**知识图谱**

- 中文检索医家 / 著作 / 观点 / 征象 / 证候，支持异名与观点全文匹配
- 按节点类型（十类）、关系类型与**诊法模态**（舌·脉·腹·目）三重筛选
- 方剂节点展示逐味药的**原剂量、炮制与君臣佐使**，加减关系附触发条件
- 点选节点查看关系网与逐条原文证据、章节路径、段落编号
- 关系可点击跳转，支持顺藤摸瓜式溯源
- 深链接：`explorer.html?q=腹诊` 直接定位到指定节点
- 桌面端鼠标拖拽 / 滚轮缩放，移动端单指平移 / 双指缩放
- 键盘快捷键：`/` 搜索、`F` 全景、`T` 切换主题、`Esc` 关闭、`?` 帮助

**双主题**：宣纸（浅）/ 墨夜（深），跨页面记忆，默认跟随系统。

## 数据集

`data/` 下为机器可读导出，所有关系均带出处字段
（`source_sentence` · `chapter_path` · `passage_id` · `evidence_verbatim` · `engine` · `agreement`）。

| 文件 | 说明 |
| --- | --- |
| `shaopai_kg.json` | 主数据集，含本体、受控词表、全部节点与关系及**完整**出处 |
| `corpus_shaopai.json` | 自原书复原的分段语料（1,586 段），带章节路径 |
| `nodes.csv` / `edges.csv` | Neo4j 导入格式，含布局坐标与连通分量 |
| `shaopai_instances.ttl` | RDF A-Box，以 `rdf:Statement` 具体化承载出处 |
| `layout_positions.json` | 全部 4,317 个节点的布局坐标，保证渲染可复现 |
| `load_neo4j.cypher` | 约束、索引与分批 `LOAD CSV` |
| `example_queries.cypher` | 六个可直接运行的图遍历示例 |
| `QC_AUDIT.md` / `qc_audit.json` | 质检报告 |
| `pilot_validation.json` | 试抽取评分及其未测项 |

Neo4j 导入：把 `nodes.csv`、`edges.csv` 放入 DBMS 的 `import/` 目录后

```bash
cat data/load_neo4j.cypher | cypher-shell -u neo4j -p <password>
```

RDF 查询：Turtle 中所有中文字面量带 `@zh` 语言标记，SPARQL 需写 `"腹诊"@zh`，
写成 `"腹诊"` 会静默返回空结果。

> 页面内嵌的图谱为**精简副本**：每个节点最多保留 8 条原文出处以控制体积，
> 完整出处请用 `data/shaopai_kg.json`。

## 构建状态与限制

本体 **1.1.0** 定义 13 类 / 27 关系；四个抽取层**全部完成**：

| 层 | 状态 | 抽取方式 |
| --- | --- | --- |
| 谱系层（医家·著作·学术观点） | 完成 | 单模型 LLM |
| 诊法层（舌·脉·腹·目诊） | 完成 | 单模型 LLM |
| 本草方剂层（方剂·中药·医案） | 完成 | **确定性解析器** |
| 证候层（病证·证候·治法） | 完成 | **确定性解析器** |

后两层不由语言模型抽取，而是对原书结构规整的章节做确定性解析（`tools/` 下可复跑），
**同一输入必得同一图谱**。两处校验：

- 本草层——蒿芩清胆汤 8/8 味全中，与上游 `pilot_validation.json` 的金标准一致
- 证候层——病证分类的抽出条数与原书自报条数逐项吻合（5/21/16/4/5），
  且每个病名都在原文中逐字命中

### 本体扩展 1.0.0 → 1.1.0

原书明言「伤寒本证…分小伤寒、大伤寒、两感伤寒、伏气伤寒、阴证伤寒5端」，
但 1.0.0 没有任何病证之间的关系，51 个病证只能成为孤点。故增补一条
`subDiseaseOf`（病证→病证，0..1），**其余一字未动**。

### 三个仍为空的类

| 类 | 原因 |
| --- | --- |
| `Symptom` 症状 | **刻意留空**。18 个常见症状候选中 17 个已是 `DiagnosticSign` 节点（modality 为问诊/望诊者 672 个）。另立一类只会重复节点、割裂图谱。 |
| `Dosage` 剂量炮制 | **刻意留空**。剂量、炮制与君臣佐使挂在 `hasIngredient` / `ingredientRole` 关系上，而非另立千余个节点。 |
| `HerbProperty` 药性 | 未抽取。原书的药性论述是散文体，解析器无法在不作推断的前提下读出。 |

### 限制（详见 `data/QC_AUDIT.md`）

1. 谱系层与诊法层的关系为**单模型抽取**，`agreement` 为 `single_engine`，交叉验证未运行。
2. **97.0%** 的关系有逐字原文证据，其余标注 `evidence_verbatim=false`。
3. **96.9%** 的关系仅有一处文献支撑；1,149 项诊法征象只出现一次。
4. **药名未作归一**：生枳壳与枳壳、炙甘草与甘草各自成点。剥离前缀的方案已被否决——
   它会把陈皮 / 青皮 / 新会皮一并压成「皮」。
5. 方剂节点须**原书印有配伍**，或与其他实体有明确关系；仅被提及方名者不立，以免产生孤点。
6. **57 个伤寒病证自成一株独立子树**——本体中没有把病证系于医家或方剂的关系。
7. 治法取自少数以「X宜Y」句式陈述治则的段落；仅在散文中论及的治法未被捕获。
8. 六淫诸证的 `patternOfDisease` 依据是原书把它们归在「X病药」一节之下，
   而非某句明确断言其归属。
9. 796 项诊法征象未抽出所提示的证候，呈孤点。
10. **段落编号有两套体系**：前两层沿用上游 `p#####`，后两层用 `b#####`
    （本次对原书 .doc 的重新切分），两套不同源，不可直接对齐；核验以逐字原文与章节路径为准。
11. 356 部著作中有 11 条实为参考文献中的期刊论文题名。

本体校验：定义域/值域违例 0 / 3,144，悬空端点 0，全部关系带出处。

## 重建流程

```bash
python3 tools/build_materia_kg.py --write   # 抽取本草方剂层并并入 shaopai_kg.json
python3 tools/build_pattern_kg.py --write   # 抽取证候层（含本体 1.1.0 扩展）
python3 tools/export_csv.py                 # 重建 nodes.csv / edges.csv
python3 tools/export_rdf.py                 # 重建 shaopai_instances.ttl
python3 tools/build_payload.py              # 重建两个页面的内嵌数据与布局
```

新增节点的坐标用「锁定既有节点、只松弛新节点」的力导向布局求解，
既有坐标一字不动——上游承诺每次渲染可复现，重排全图会毁掉这个性质。

## 部署

站点通过 GitHub Actions 发布，配置见 `.github/workflows/jekyll-gh-pages.yml`：

- **Settings → Pages → Source** 为 `GitHub Actions`
- 每次推送到 `main` 自动触发构建与部署，也可在 **Actions** 页手动运行
- 从推送到线上可见约需 1–2 分钟；期间访问会短暂出现 404，属正常现象

页面均无 YAML front matter，Jekyll 将其作为静态文件原样拷贝，不做 Liquid 解析，
因此页面内的 `{` `}` 等字符不会被改写。

> 若日后新增页面，避免在文件开头写 `---` 分隔的 front matter，也避免使用以
> `_` 开头的文件名或目录——两者都会被 Jekyll 特殊处理。

## 设计语汇

取绍兴地方文化意象：宣纸底色、松烟墨字、越窑青瓷绿、绍兴黄酒琥珀、朱砂印章，
配以白墙黛瓦、石拱桥、乌篷船与鉴湖水波。十类节点分取朱砂（医家）、天青（著作）、
青瓷（学术观点）、缃色（诊法征象）、藕荷（证候）、胭脂（方剂）、柳芽（中药）、
石青（治法）、月白（医案）、赭石（病证）。中文标题用楷体，正文用宋体，
数字与标签用无衬线体，字体全部取自系统，无外链。
