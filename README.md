# 绍派伤寒 · 越医知识图谱

> **沈钦荣名中医 × 医哲未来人工智能研究院 联合研发**
> Jointly developed by Dr. Shen Qinrong & IMPFAI

绍派伤寒（Shaoxing Cold-Damage School）与越医传统的学术知识图谱网页版。发端于明代张景岳，
形成于清代俞根初《通俗伤寒论》，光大于何廉臣，今由沈钦荣在骨伤科门诊延续——以图谱之形重现
越中外感病学派的医家、著作、学说、四诊征象、证候治法、方药医案，以及越地医学世家、医事机构与籍贯地域。

**当前版本 V7**：**18,149 节点 / 22,698 关系**，抽取自**八种文献**，**每条关系都带上游段落编号与实际抽取引擎**。
本体 1.2.0 定义 20 类 / 46 关系，本站 15 类 / 32 关系已有实例；最大连通分量 **9,469 节点**，
另有 637 个卫星分量与 7,087 个尚无关系的孤点。定义域/值域违例、自环、重复关系、悬空端点**均为 0**。

上游本次还交付了沈钦荣 2022—2026 年骨伤科门诊病案 131 则（5,682 条关系、1,234 个只由它引出的节点）。
**这一层的逐案记录在去标识化复核完成、并由数据方确认发布授权之前不进入本站**；
本站只发布其聚合统计，且只含至少 3 例的条目（`data/modern_case_profiles.csv` 与主页「当代门诊」一节），见下文「当代病案」。

## 出处与原文核验（V7 新增）

- **段落编号**：上游这次随图谱交付了 `nodes.csv` / `edges.csv`，其中**每一条关系**都带段落编号
  与实际抽取引擎。V5、V6 由浏览器载荷还原，没有段落编号、引擎只能按层推定——这一限制已解除。
- **语料**：`data/corpus_yueyi.json` 收七种文献共 4,395 段，关系的段落编号可在其中逐条核对。
  《绍派伤寒》专著的 4,330 条关系沿用上游旧的 `p#####` 编号，本仓库的 `corpus_shaopai.json`
  是另一套 `b#####` 重切分，两者无法对应。
- **独立核验**：导入时逐条检查「原文句是否真在所引段落里」（规范化空白与全半角，
  也接受以「 / 」分隔、各段分别命中的多段引文），结果写入每条关系的 `evidence_in_passage`：

  | | 条数 |
  | --- | ---: |
  | 可解析段落的关系 | 18,368 |
  | 原文见于所引段落 | 17,788（96.8%） |
  | 未见于所引段落 | 580 |
  | ——其中上游标为「逐字」 | 312 |
  | 段落无法解析（《绍派伤寒》p##### 编号） | 4,330 |

  上游标为逐字却找不到的，多是把医案标题当作证据（标题不在正文段落里）。
  浏览器中这类关系标「[原文未见于所引段落]」。上游的 `evidence_verbatim` 标记原样保留，两者并列。
- **引擎**：`builtin-haiku` 20,698 · `builtin-sonnet` 1,674 · `builtin-haiku+vocab` 326；
  后者的 `agreement` 为 `vocabulary_bridge`（词表辅助），其余为 `single_engine`。

## 当代病案

上游交付的第九种语料是沈钦荣 2022—2026 年骨伤科门诊病案 131 则。它们是**在世患者**的真实记录，
上游做过一轮去标识化（身份证号、病历号、姓名替换为 `case-YYYY-NNN`），本仓库复核认为尚不足以公开：
记录仍保留性别、年龄、确切就诊日期与完整病史。因此：

- **默认不发布逐案记录**。导入脚本删去该语料的全部 5,682 条关系、只由它引出的 1,234 个节点
  （含西医诊断、外治操作、西药、辅助检查四类的全部实例），并把受其影响的 290 个节点的属性、
  出处与坐标恢复为上一版——全图几何与线上版本一致。
- **聚合统计只发布至少 3 例的条目**：上游聚合表 61 行中有 52 行只有 1–2 例（47 行各对应一名患者），
  实为个人诊疗概况，随逐案记录一并暂缓；`data/modern_case_profiles.csv` 保留其余 9 行，
  主页「当代门诊」一节用同一门槛。
- **发布逐案记录**需要数据方确认已获患者同意或伦理批准，然后运行
  `import_upstream.py … --include-modern-cases`。该开关先经 `tools/deidentify.py` 去标识化
  （行内患者抬头、残留编号、日历日期只留年份——含漏写「日」字与诊次前的残缺写法、就诊跨度与逐次就诊日期
  改写为天数、90 岁以上合并），
  再过隐私闸门——逐字段核验，任何残留都会使导入中止、不写任何文件。

两种模式下，写盘前都会对**全部输出文本**跑同一道隐私闸门：患者抬头、身份证号、手机号，
以及运行时从原始文本推导出的患者姓名，都必须为 0。

## 沈钦荣门诊医案 · 本地查阅

逐案记录不随网站发布，但持有上游交付的研究者可以在图谱里**本地**查阅：

```bash
U=path/to/upstream_delivery
python3 tools/export_modern_cases.py --explorer $U/shaopai_explorer.html \
    --nodes-csv $U/nodes.csv --edges-csv $U/edges.csv --ontology $U/ontology_spec.json \
    --corpus $U/corpus_yueyi.json --out ~/shaopai_modern_cases.local.json
```

然后打开 `explorer.html`（或 `explorer.html?cases`）→ 顶栏「沈钦荣医案」→ 选择这个文件。

- **数据不出本机**：文件由浏览器在本地读取，载入后页面不发任何网络请求。勾选「记住」才存进本浏览器的
  IndexedDB，面板里「清除本机数据」随时删除；不勾选则关闭页面即消失。
- **与图谱合一**：131 则医案、1,059 个未公开实体、5,682 条关系并入当前图谱，新实体的坐标按公开布局求解
  （公开节点不动）。面板可按西医诊断、年份筛选，检索诊断、证候、方药、外治、症状与原文；点选一案即在图上定位，
  详情面板给出去标识化的病案摘要、原文与全部关系。桂枝、白芍这类共用节点同时列出古籍与门诊两侧的关系；
  「图谱中只显示门诊医案的关系」一键过滤。
- **深链接**：`explorer.html?cases` 打开面板；数据载入（或已记住）后，`explorer.html?case=case-YYYY-NNN`
  直达某案。
- **去标识化**：与 `import_upstream.py --include-modern-cases` 同一套规则（`tools/deidentify.py`），
  写盘前对每个字符串字段做严格核验，任何残留都会中止、不写文件。医案节点的上游原始属性（英文病家描述、
  就诊跨度备注）不导出，由面板里的中文摘要代替。
- **防止误提交**：脚本默认拒绝写入仓库目录，`*.local.json` 已列入 `.gitignore`。请勿转发或上传该文件。
- V1 两书版不含此功能。

## 功能

**主页**

- 江南水乡首屏场景（会稽远山、白墙黛瓦、石拱桥、鉴湖水波、乌篷船），支持鼠标视差
- 学派源流时间轴：明代张景岳 → 清代俞根初 → 何秀山 / 章虚谷 / 赵晴初 → 何廉臣 → 曹炳章 / 胡宝书 → 徐荣斋 → 当代
- 学术特色六端，每条均附原书文句与出处医家
- 代表医家十二家卡片（观点数、关联数、医案数、异名由图谱统计），点击直达图谱对应节点
- 诊法层 · 方治层 · 医案层：模态分布、六经与性质坐标、方剂主治、治法用方、病证 × 用药共现
- **当代门诊**（V7 新增）：何廉臣医案与沈钦荣门诊对照；西医诊断 → 中医病名、证候、用药、方剂、外治——
  桂枝是当代门诊用得最多的药，「和解少阳」出现在 12 案中，伤寒家法延续到骨伤科
- 越医文化层：籍贯地域、医学世家、医事机构与团体、层覆盖
- 图谱实时预览；首屏、图谱一节与页脚均有 **V1 两书版** 入口

**知识图谱**

- 中文检索医家 / 著作 / 观点 / 征象 / 证候 / 医案 / 方药 / 机构，匹配名称、异名与全部属性
- 四重筛选：**来源文献**、**抽取层**、**关系类型**、**诊法模态**，外加节点类型开关与**孤点**一键隐藏
- 点选节点查看属性、关系网与每条关系的原文、**段落编号**、来源文献、章节路径、所属层与引擎；
  上游标「非逐字」与独立核验「未见于所引段落」分别标出
- 深链接：`explorer.html?q=蒿芩清胆汤`；桌面拖拽 / 滚轮缩放，移动端单指平移 / 双指缩放
- 键盘快捷键：`/` 搜索、`F` 全景、`T` 切换主题、`Esc` 关闭、`?` 帮助

## 本体

本体 **1.2.0** 取自上游 `ontology_spec.json`，**原样采用**：20 类、46 对象属性，每条属性带定义域、值域与基数。
相对 1.1.0 新增四类（西医诊断、外治操作、西药、辅助检查）与七条关系（医案西医诊断、医案外治操作、
医案西药、医案辅助检查、医案既往史、西医病名对应中医病名、检查支持诊断），全部只用于当代病案。

基数按上游声明**如实报告、不再改写**：声明为 0..1 的七条属性中，有 55 个主语带多条出边——
籍贯 20 · 源自 14 · 载于 11 · 属于六经 3 · 属于世家 3 · 子证候 2 · 机构所在 2。
这七条属性在 OWL 导出中**不声明为 `owl:FunctionalProperty`**，否则推理机会把同一主语的不同宾语
推断为同一实体（例如把两部不同的著作合并）。V5、V6 的做法是把它们改成 0..*，自 V7 起改为保留声明、报告例外。

数据中出现但规格未声明的属性（如 `Herb.dose`、`Formula.base_formula`）列在 `qc_audit.json` 的
`undeclared_attrs` 中，并在 T-Box 中带注释导出。

## 已知限制（详见 `data/QC_AUDIT.md`）

1. **单引擎抽取**：MiniMax 交叉验证从未运行。
2. 越医文化层覆盖 74.9%、本草方剂层 83.0%，两层导出的任何计数都是下界。
3. 97.8% 的关系上游标为逐字，501 条标「非逐字」；独立核验另有 312 条标为逐字却未见于所引段落。
4. 《绍派伤寒》专著的 4,330 条关系的段落编号无法用本仓库语料解析。
5. **98.5%** 的关系仅有一处文献支撑。
6. 7,087 个节点尚无关系，浏览器把它们铺在最外一圈，可一键隐藏。
7. 医案标题仅 255/660 含规范病名，其余以证候命名。
8. **药名不作归一**：道地与品质前缀刻意保留，仅归并炮制前缀。
9. 症状与诊法征象两类有 439 个同名节点并存。
10. 繁简归并只作用于节点名称；机构 `kind` 等属性值仍有两写。
11. 方剂的逐味配伍未随交付提供，「药物组成」仅 41 条。
12. 按本体声明的 0..1 基数有 55 个例外，见上「本体」。
13. 当代病案的逐案记录暂缓发布，见上「当代病案」。

## 重建流程

```bash
U=path/to/upstream_delivery
# 1. 导入（默认不发布当代病案的逐案记录）
python3 tools/import_upstream.py --explorer $U/shaopai_explorer.html \
    --nodes-csv $U/nodes.csv --edges-csv $U/edges.csv --ontology $U/ontology_spec.json \
    --layout $U/layout_positions.json --corpus $U/corpus_yueyi.json \
    --profiles $U/modern_case_profiles.csv
#    → data/shaopai_kg.json · layout_positions.json · qc_audit.json · disease_profiles.csv
#      corpus_yueyi.json · modern_case_profiles.csv
# 2. 导出
python3 tools/export_csv.py        # nodes.csv · edges.csv · load_neo4j.cypher
python3 tools/export_rdf.py        # shaopai_instances.ttl
python3 tools/export_ontology.py   # shaopai_ontology.ttl
# 3. 站点内嵌数据
python3 tools/build_payload.py     # explorer.html 的内嵌图谱 + index.html 的预览子集 + v1.html（V1 两书版）
```

只给 `--explorer` 也能导入（V5 / V6 的做法，但没有段落编号）；有上游完整主图谱时用 `--kg`。
全部脚本只依赖 Python 3 标准库。`python3 tools/deidentify.py` 可运行去标识化自检（只用虚构样例）。

## 部署

站点通过 GitHub Actions 发布，配置见 `.github/workflows/jekyll-gh-pages.yml`：

- **Settings → Pages → Source** 为 `GitHub Actions`

> 若日后新增页面，避免在文件开头写 `---` 分隔的 front matter，也避免使用以
> `_` 开头的文件名或目录——两者都会被 Jekyll 特殊处理。

## 设计语汇

取绍兴地方文化意象：宣纸底色、松烟墨字、越窑青瓷绿、绍兴黄酒琥珀、朱砂印章，
配以白墙黛瓦、石拱桥、乌篷船与鉴湖水波。十五类节点分取朱砂（医家）、天青（著作）、
青瓷（学术观点）、缃色（诊法征象）、藕荷（证候）、胭脂（方剂）、柳芽（中药）、
石青（治法）、月白（医案）、赭石（病证）、竹青（症状）、青灰（药性）、紫藤（机构团体）、
青碧（地域）、沉香（医学世家）；当代病案四类预留珊瑚、艾绒、瓷蓝、青瓷灰。
中文标题用楷体，正文用宋体，数字与标签用无衬线体，字体全部取自系统，无外链。
