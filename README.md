# 绍派伤寒 · 越医知识图谱

> **沈钦荣名中医 × 医哲未来人工智能研究院 联合研发**
> Jointly developed by Dr. Shen Qinrong & IMPFAI

绍派伤寒（Shaoxing Cold-Damage School）与越医传统的学术知识图谱网页版。发端于明代张景岳，
形成于清代俞根初《通俗伤寒论》，光大于何廉臣——以图谱之形重现越中外感病学派的医家、著作、学说、
四诊征象、证候治法、方药医案，以及越地医学世家、医事机构与籍贯地域。

**当前版本 V6**：**18,151 节点 / 22,700 关系**，抽取自**八种文献**、分**六层**——谱系层、诊法层、
证候层、本草方剂层、医案层、越医文化层。本体 1.1.0 定义 16 类 / 39 关系，其中 15 类 / 32 关系已有实例；
最大连通分量 **9,471 节点**，另有 637 个卫星分量与 7,087 个尚无关系的孤点。
本版自环、重复关系、悬空端点与定义域/值域违例**均为 0**。

## 功能

**主页**

- 江南水乡首屏场景（会稽远山、白墙黛瓦、石拱桥、鉴湖水波、乌篷船），支持鼠标视差
- 学派源流时间轴：明代张景岳 → 清代俞根初 → 何秀山 / 章虚谷 / 赵晴初 → 何廉臣 → 曹炳章 / 胡宝书 → 徐荣斋 → 当代整理与智能化
- 学术特色六端，每条均附原书文句与出处医家
- 代表医家十二家卡片（观点数、关联数、医案数、异名由图谱统计），点击直达图谱对应节点
- 诊法层：征象模态分布、证候的六经与性质坐标、六经统六法、症状与病证
- **方治层**：方剂主治的证候数、治法用方、方剂源流——V6 随《俞根初临证经验集要》新增
- 医案层：病证 × 用药共现表、最常用药物与最常见症状、治法与成方
- 越医文化层：籍贯地域、医学世家、医事机构与团体、六层覆盖
- 图谱实时预览（取真实布局坐标绘制 420 个高连通节点）
- 机器可读数据集下载

**知识图谱**

- 中文检索医家 / 著作 / 观点 / 征象 / 证候 / 医案 / 方药 / 机构，匹配名称、异名与全部属性；名称命中优先于长句陈述
- 四重筛选：**来源文献**（八种）、**抽取层**（六层）、**关系类型**（32 种）、**诊法模态**（舌·脉·腹·目…），
  外加十五类节点开关与**孤点**一键隐藏
- 点选节点查看属性、关系网与每条关系的原文证据、来源文献、章节路径、所属层与抽取引擎
- 关系可点击跳转，支持顺藤摸瓜式溯源
- 深链接：`explorer.html?q=蒿芩清胆汤` 直接定位到指定节点
- 桌面端鼠标拖拽 / 滚轮缩放，移动端单指平移 / 双指缩放；视口变化时画面中心保持不动
- 键盘快捷键：`/` 搜索、`F` 全景、`T` 切换主题、`Esc` 关闭、`?` 帮助
- 1.8 万节点按类分批绘制，重绘经动画帧合并、光晕限于度数最高的 260 个枢纽，实测稳定 60 fps

**双主题**：宣纸（浅）/ 墨夜（深），跨页面记忆，默认跟随系统。

**出处深度**：本仓库的 `data/` 与两个页面均由上游随图谱交付的**自包含浏览器内嵌载荷**还原——
每条关系 1 条原文与章节路径、每个节点最多 3 条章节路径与 1 条原文，**不含段落编号**
（`passage_id` 列为空）。完整出处以上游 `shaopai_kg.json` 为准；拿到该文件后用
`tools/import_upstream.py --kg` 重新导入即可，字段按原样保留。

Neo4j 导入：把 `nodes.csv`、`edges.csv` 放入 DBMS 的 `import/` 目录后

```bash
cat data/load_neo4j.cypher | cypher-shell -u neo4j -p <password>
```

RDF 查询：Turtle 中所有中文字面量带 `@zh` 语言标记，SPARQL 需写 `"腹诊"@zh`，
写成 `"腹诊"` 会静默返回空结果。

## 已知限制（详见 `data/QC_AUDIT.md`）

1. **单引擎抽取**：MiniMax 交叉验证从未运行（密钥仅以聊天文本提供，未写入执行环境），
   所有关系 `agreement=single_engine`。
2. 越医文化层覆盖 74.9%、本草方剂层 83.0%，两层导出的任何计数都是下界。
3. **97.8%** 的关系有逐字原文证据，501 条标注 `evidence_verbatim=false`；20 条关系无原文句（仅有章节路径）。
4. **98.5%** 的关系仅有一处文献支撑。
5. 7,087 个节点没有任何已抽取关系（多为单次出现的症状、治法短语）；浏览器把它们铺在最外一圈，可一键隐藏。
6. 医案标题仅 255/660 含规范病名，其余以证候命名，成为证候节点。
7. **药名不作归一**：道地与品质前缀（广、川、杭、建、云、西、陈、真、原）刻意保留，仅归并炮制前缀。
8. 症状与诊法征象两类有 439 个同名节点并存——两层抽取各自命名所致，检索时请同时查看两类。
9. **繁简归并只作用于节点名称**：机构 `kind` 等**属性值**仍有 學校 / 学校、醫社 / 医社 两写。
10. 方剂的**逐味配伍**（君臣佐使与原剂量）未随本次交付提供，「药物组成」仍为 41 条，
    `ingredientRole` / `hasDosage` 等四条关系无实例。
11. 中药节点上的 `dose` / `unit` 是原文所见的抽取值（含「钱半 = 1.5 钱」的换算），不是药典常规剂量。

## 重建流程

```bash
# 1. 导入上游交付（二选一）
python3 tools/import_upstream.py --explorer path/to/shaopai_explorer.html   # 上游自包含浏览器
python3 tools/import_upstream.py --kg path/to/shaopai_kg.json               # 上游完整主图谱
#    → data/shaopai_kg.json · layout_positions.json · qc_audit.json · disease_profiles.csv
# 2. 导出
python3 tools/export_csv.py        # nodes.csv · edges.csv · load_neo4j.cypher
python3 tools/export_rdf.py        # shaopai_instances.ttl
python3 tools/export_ontology.py   # shaopai_ontology.ttl
# 3. 站点内嵌数据
python3 tools/build_payload.py     # explorer.html 的内嵌图谱 + index.html 的预览子集
```

全部脚本只依赖 Python 3 标准库，几秒内跑完。导入脚本兼容上游两代载荷字段名
（关系原文键 V6 用 `ev`、V5 用 `e`）。布局坐标以上游烘焙值为准；若日后有节点缺坐标，
`build_payload.py` 用「锁定既有节点、只松弛新节点」的力导向布局补齐，既有坐标一字不动。

## 部署

站点通过 GitHub Actions 发布，配置见 `.github/workflows/jekyll-gh-pages.yml`：

- **Settings → Pages → Source** 为 `GitHub Actions`
- 每次推送到 `main` 自动触发构建与部署，也可在 **Actions** 页手动运行
- 从推送到线上可见约需 1–2 分钟；期间访问会短暂出现 404，属正常现象

页面均无 YAML front matter，Jekyll 将其作为静态文件原样拷贝，不做 Liquid 解析，
因此页面内的 `{` `}` 等字符不会被改写。

> 若日后新增页面，避免在文件开头写 `---` 分隔的 front matter，也避免使用以
> `_` 开头的文件名或目录——两者都会被 Jekyll 特殊处理。

## 设计语汇

取绍兴地方文化意象：宣纸底色、松烟墨字、越窑青瓷绿、绍兴黄酒琥珀、朱砂印章，
配以白墙黛瓦、石拱桥、乌篷船与鉴湖水波。十五类节点分取朱砂（医家）、天青（著作）、
青瓷（学术观点）、缃色（诊法征象）、藕荷（证候）、胭脂（方剂）、柳芽（中药）、
石青（治法）、月白（医案）、赭石（病证）、竹青（症状）、青灰（药性）、紫藤（机构团体）、
青碧（地域）、沉香（医学世家）。中文标题用楷体，正文用宋体，数字与标签用无衬线体，
字体全部取自系统，无外链。
